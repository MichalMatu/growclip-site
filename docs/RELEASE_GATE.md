# Final release gate

Scope: static marketing site only. Do not deploy until separately authorized.

- S5: both prerendered locales, canonical/hreflang and social image, sitemap, mobile navigation and keyboard, explicit build-size budgets.
- S6: PL/EN × light/dark × desktop/mobile; screenshot hero, demo, gallery and CTA; check no horizontal overflow, asset integrity, console and critical accessibility findings.
- Final: full lint, typecheck, Vitest, Playwright strict accessibility, static build, documented evidence and clean main. Record rollback source SHA and any residual issues.
- Explicitly deferred: owner-provenance prototype photography. No product firmware, device access, live MQTT, or Telegram operations. Visual screenshots must be inspected before claiming visual acceptance.
